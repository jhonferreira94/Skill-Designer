# Análise de Produtos de Referência (Benchmarking)

Estudar produtos modelo para extrair padrões comprovados de fluxo, layout,
linguagem e componentes — adotando o que funciona e evitando o que não funciona.

## ⚠️ Pré-requisito
Os **projetos de referência são sempre confirmados com o usuário** no início da
skill. Use os modelos informados (ou as referências padrão abaixo, se aprovadas)
como base desta análise.

## Referências padrão (Figma)
- **WK – Protótipo**: https://www.figma.com/design/prkihUzzfMmLed4YzC8qcS/WK-Prot%C3%B3tipo?node-id=2-2919
- **Aplicativo**: https://www.figma.com/design/g62K87Ng0esV1KhCl7BKab/Aplicativo?node-id=0-1

> Esses arquivos do Figma exigem acesso autenticado. Se não for possível abri-los,
> solicite ao usuário prints, os nomes dos frames/fluxos relevantes ou acesso ao
> arquivo antes de seguir com a análise.

## O que analisar em cada referência
- **Onboarding e primeiro uso**: como apresentam valor rapidamente.
- **Navegação e AI**: estrutura, tab bar, hierarquia, rótulos.
- **Fluxos-chave**: passos, atritos, defaults, microcopy.
- **Padrões de UI**: layout, componentes, estados, vazios (empty states), erros.
- **Identidade visual**: cores, tipografia, densidade, ilustração/ícones.
- **Acessibilidade**: contraste, tamanho de alvo, foco.

## Processo
1. Liste 2–4 referências (as informadas pelo usuário).
2. Para cada uma, capture telas/fluxos relevantes ao escopo.
3. Preencha a tabela comparativa abaixo.
4. Extraia **padrões a adotar**, **a evitar** e **oportunidades** (gaps).
5. Traduza os padrões escolhidos para componentes/tokens do Gluestack.
