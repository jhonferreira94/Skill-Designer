# Regras

Acervo de **regras** da skill **designer** — convenções e armadilhas
aprendidas na prática, separadas das referências conceituais (`../references/`).

Cada arquivo é uma regra por tema. Para adicionar uma nova regra, crie um
`.md` aqui e linke no índice abaixo e no `SKILL.md`.
